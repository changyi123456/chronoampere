# 電的時光旅人 · CHRONOAMPERE

> 穿越時空的科學史探險 — 一款以電磁學為主題的 3D 物理解謎 RPG（海龜湯推理）。

搭乘「時光電弧儀」回到電磁學六個關鍵時刻，**用實驗器材親手重現**歐姆、克希何夫、湯姆森、布勞恩、法拉第與變壓器時代的實驗；每重現一項就答一道選擇題、取得一張「殘頁」，集滿六張後拼出一道時間迴圈（bootstrap 悖論）的海龜湯真相。

## 六個關卡（對應高中電磁學三章）
1. **歐姆的串聯電路**（Ch1 歐姆定律 / 焦耳熱）
2. **克希何夫的並聯電路**（Ch1 節點定則）
3. **湯姆森測電子荷質比 e/m**（Ch2 帶電質點圓周運動）
4. **布勞恩的陰極射線管 CRT 偏轉**（Ch2 電場/磁場偏轉）
5. **法拉第的交流發電機**（Ch3 電磁感應）
6. **降壓變壓器**（Ch3 變壓器）

每關都是**真實時間演化模擬**（固定時間步數值積分），含 Play/Pause/Reset、即時示波器、即時讀數，過關需「多重物理條件同時達成」。

## 特色
- 3D 實驗室器材（電池、滑動變阻器、燈泡、亥姆霍茲線圈、陰極射線管、發電機、變壓器…），可用滑鼠/觸控直接操作（旋鈕繞圈、變阻器拖滑塊）
- AAA 渲染：環境反射、接觸陰影、ACES 色調、發光泛光
- 時空樞紐 Hub + 引導 NPC「AMP」+ RPG 對話框 / 任務日誌彈窗
- 入口時空穿梭隧道動畫、音效與背景音樂、手機自適應排版

## 技術
Vite · React 19 · TypeScript · Three.js · @react-three/fiber · @react-three/drei

## 開發 / 執行
```bash
npm install
npm run dev      # 開發 http://localhost:5173
npm run build    # 產出 dist/
```

## 操作
WASD／方向鍵移動，走近時光之門按 E 進入；進關後按 ▶啟動 跑模擬，滑鼠拖曳旋轉視角、操作儀器；右上角可靜音。

## 背景音樂
`public/bgm.mp3`（請自行放入喜歡的音樂；範例使用者放入了 Interstellar 主題）。若無此檔，程式會以程序式環境音作為襯底。
